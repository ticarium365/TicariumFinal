SPRINT 5 — Tedarikçi / Alış Yönetimi Modülü

AMAÇ:
SMSYSTEMS’i sadece satış ve stok yöneten sistem olmaktan çıkarıp satın alma, tedarikçi borcu, maliyet takibi ve ürün giriş operasyonunu yöneten tam işletme sistemine çevirmek.

Bu sprint sonunda kullanıcı:

* tedarikçi ekleyebilecek
* alış faturası girebilecek
* ürün stoğunu alış ile artırabilecek
* tedarikçi borcunu takip edebilecek
* ürün maliyet geçmişini görebilecek
* alış raporları alabilecek

==================================================
GENEL TESLİM KURALLARI
======================

* Multi-tenant izolasyonu zorunlu
* company_id scope tüm sorgularda uygulanacak
* standart error formatı kullanılacak
* audit log aktif olacak
* integration test yazılacak
* responsive UI olacak
* docs güncellenecek

==================================================
BAKİYE HESAP MANTIĞI
====================

current_balance = toplam debit - toplam credit

Örnek:
20.000 alış faturası = debit
8.000 ödeme = credit

Borç = 12.000

==================================================
BACKEND API
===========

1. Tedarikçi CRUD

GET /api/suppliers
GET /api/suppliers/:id
POST /api/suppliers
PUT /api/suppliers/:id
DELETE /api/suppliers/:id   (soft delete)
PATCH /api/suppliers/:id/restore

---

2. Alış Faturası

GET /api/purchases
GET /api/purchases/:id

POST /api/purchases

Body:
{
supplierId,
invoiceNo,
invoiceDate,
items: [
{
productId,
quantity,
unitCost
}
],
taxAmount,
discountAmount,
note
}

İşlem Sonucu:

* purchases kaydı oluşur
* purchase_items oluşur
* products.stock_quantity artar
* purchase price güncellenir (kurala göre)
* stock_movements içine purchase hareketi oluşur
* supplier_transactions içine debit oluşur
* supplier.current_balance artar

PUT /api/purchases/:id
(ilk sürümde sınırlı düzenleme)

---

3. Tedarikçi Ödeme

POST /api/suppliers/:id/payment

Body:
{
amount,
paymentMethod,
note
}

İşlem:

* supplier_transactions içine credit
* current_balance düşer
* audit log

---

4. Manuel Düzeltme

POST /api/suppliers/:id/adjustment

Body:
{
amount,
direction,
note
}

---

5. Raporlar

GET /api/purchases/recent
GET /api/purchases/summary
GET /api/suppliers/top-creditors
GET /api/suppliers/:id/statement
GET /api/products/:id/cost-history

==================================================
BACKEND İŞ KURALLARI
====================

* viewer alış faturası giremez

* viewer ödeme giremez

* staff opsiyonel sadece alış girebilir

* admin tam yetki

* quantity > 0 olmalı

* unitCost >= 0

* items boş olamaz

* silinmiş tedarikçiye işlem yapılamaz

* silinmiş ürüne alış girilemez

* aynı fatura no duplicate warning verebilir

* ödeme amount > 0
