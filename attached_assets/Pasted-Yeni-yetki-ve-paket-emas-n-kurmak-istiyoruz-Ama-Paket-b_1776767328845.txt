Yeni yetki ve paket şemasını kurmak istiyoruz.

Amaç:
Paket bazlı ürün erişimi + rol bazlı kullanıcı yetkisi + hesap tipi ayrımı.

TEMEL MANTIK:

1. Paket = firmanın satın aldığı plan
2. Feature set = paketin açtığı modüller
3. Rol = kullanıcı bazlı yetki seviyesi
4. Account type = işletme hesabı mı, satınalmacı hesabı mı

PAKET MANTIĞI:
inventory:
stok + ürün + barkod + etiket + temel rapor

commerce:
inventory + satış + pos + müşteri + alış/satış hareketleri

business:
commerce + finans + banka + tedarikçi + gelişmiş rapor

growth:
business + pazaryeri + storefront + büyüme araçları + gelişmiş fiyatlama

enterprise:
growth + e-fatura + entegrasyonlar + api + multi-branch + personel + b2b

trial_enterprise:
21 gün boyunca enterprise feature set açsın

procurement:
satınalmacıya özel; ürün görüntüleme, firma görüntüleme, teklif isteme, karşılaştırma, export basic, favoriler, kullanıcı yönetimi basic
ama satış/pos/finans/e-fatura/marketplace/storefront yönetimi olmasın

ROL MANTIĞI:
Paket üst sınırı belirlesin.
Rol o paket içinde kullanıcının erişim seviyesini belirlesin.

Örnek roller:

- owner
- admin
- manager
- staff
- accountant
- cashier
- procurement_admin
- procurement_user

MENÜ DAVRANIŞI:
Yetkisi olmayan modüller menüde kilitli görünsün.
Ancak kilit sebebi sistemde ayrışsın:

1. Paket yok
2. Rol yetkisi yok
3. Hesap tipi uygun değil

UI metinleri farklı olsun:

- paket kilidi -> plan yükselt
- rol kilidi -> yetki iste
- hesap tipi kilidi -> bu modül bu hesap tipine uygun değil
