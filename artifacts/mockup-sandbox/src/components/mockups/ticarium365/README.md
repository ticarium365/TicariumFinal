# Ticarium365 Mockup'ları

Bu klasördeki dosyalar **prototip / tasarım referansıdır**.

## Önemli

- **Source of truth burası DEĞİLDİR.** Gerçek uygulama `artifacts/prosan/` altındadır.
- Mockup'lar başlangıçta tasarım keşfi için oluşturuldu; canlı uygulama bunlardan ayrı evrildi.
- Burayı **sadece** yeni bir konsepti hızlıca canvas'ta denemek için kullanın.
- Mockup'ı değiştirmek canlı uygulamayı etkilemez. Tersi de geçerli — canlı uygulamadaki son durum bu mockup'lara yansımaz.

## Bir mockup'ı canlıya almak istiyorsanız

`mockup-graduate` skill'ini kullanın — mockup'ı `artifacts/prosan/`'ın pattern'lerine uyarlar.
